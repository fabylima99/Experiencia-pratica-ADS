# Projeto ONG - Resgate e Adoção Animal

Plataforma web para a gestão institucional, divulgação de projetos e cadastro de voluntários de uma ONG de proteção animal.

## Tecnologias e Arquitetura

- **HTML5 Semântico:** Estrutura acessível (WCAG) e otimizada para motores de busca (SEO).
- **CSS3 e Design System:** Layout responsivo com CSS Grid de 12 colunas, Flexbox e variáveis declaradas no `:root`.
- **JavaScript ES6 (Vanilla JS):** Navegação Single Page Application (SPA) modularizada em `/modules`, History API (`pushState`/`popstate`) e persistência no `localStorage`.

## Instalação e Execução Local

1. Clonar o repositório: `git clone <url-do-repositorio>`
2. Abrir a pasta no Antigravity IDE.
3. Iniciar o servidor local através da extensão Live Server no arquivo `index.html`.

## Versionamento

O projeto utilizou o fluxo Git Flow com a branch `main` mantida como versão estável e branches temáticas para o desenvolvimento das funcionalidades.
